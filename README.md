# Hermes skill tap: ics-agenda-planner

Original skill written for CSCI 599 Assignment 3 (advanced-integration option: custom skill
published as a Hermes GitHub skill tap).

```bash
hermes skills tap add jmaitreyee029-star/ics-agenda-planner-tap
hermes skills search ics-agenda
hermes skills install jmaitreyee029-star/ics-agenda-planner-tap/ics-agenda-planner
```

The skill turns any iCalendar feed (file or secret ICS URL) into an agenda, conflict list and
free-slot list. Standard-library Python only; no credentials or personal data in the repo.
Sample data in `skills/ics-agenda-planner/references/sample.ics` is synthetic.
